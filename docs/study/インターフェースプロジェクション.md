# Spring Data JPA インターフェースベース・プロジェクション

## 概要

リポジトリの抽象メソッドと、ゲッターのみを定義した DTO インターフェースを組み合わせると、Spring Data JPA が **実行時に必要なカラムだけを SELECT する SQL を自動発行し、結果を動的プロキシでマッピングしてくれる** 仕組み。

エンティティ全カラムを取得する必要がない画面（一覧表示・選択肢など）で軽量化に役立つ。

---

## 構成要素

### 1. DTO（インターフェース）

`src/main/java/com/example/rpg2/dto/AllySummary.java`

```java
package com.example.rpg2.dto;

public interface AllySummary {
    Integer getId();
    String getName();
}
```

- **インターフェースなので `new` できない**
- 取得したいカラムに対応する **ゲッターだけを宣言** する

### 2. リポジトリ（抽象メソッド）

`src/main/java/com/example/rpg2/repository/AllyRepository.java`

```java
@Repository
public interface AllyRepository extends JpaRepository<Ally, Integer> {
    List<AllySummary> findAllProjectedBy();
}
```

- メソッド本体は書かない（インターフェースの抽象メソッド）
- 戻り値型に `List<AllySummary>` を指定することで、Spring Data JPA がプロジェクション対象として認識する

### 3. 呼び出し側（Controller）

`src/main/java/com/example/rpg2/controller/StartController.java`

```java
List<AllySummary> allyList = allyRepository.findAllProjectedBy();
```

---

## SQL が自動発行される仕組み

メソッド名 `findAllProjectedBy` から Spring Data JPA がクエリを導出する。

| キーワード | 意味 |
|---|---|
| `findAll...By` | 全件取得 |
| `...ProjectedBy` | プロジェクション（部分カラム取得）を行う |

さらに、戻り値型 `List<AllySummary>` のゲッター（`getId()`, `getName()`）を見て **必要なカラムだけを SELECT** する。

発行される SQL のイメージ:

```sql
SELECT a.id AS id, a.name AS name FROM ally a;
```

`SELECT *` ではなく、ゲッターに対応する 2 カラムだけが取得される。

---

## DTO の実体はどこから来るのか

`AllySummary` はインターフェースなので、当然 `new` できない。
ここがポイントで、**Spring Data JPA が実行時に JDK Dynamic Proxy（動的プロキシ）を生成** し、`AllySummary` を実装したオブジェクトを返す。

プロキシの中身:

- `getId()` を呼ぶと、クエリ結果の `id` カラム値を返す
- `getName()` を呼ぶと、クエリ結果の `name` カラム値を返す

つまり「リポジトリ＝抽象メソッド」「DTO＝インターフェース」「実体は実行時にフレームワークが付与」という理解で正しい。

---

## まとめ

| 項目 | 内容 |
|---|---|
| SQL 発行 | メソッド名 + 戻り値型から自動導出（必要カラムのみ SELECT） |
| DTO 実体 | Spring Data JPA が実行時に動的プロキシを生成 |
| メリット | エンティティ全カラムを取らないので軽量、画面表示用に最適 |
| 注意 | DTO はインターフェースで、ゲッターのみ定義する |

---

## 参考：他のプロジェクション方式

- **クラスベース・プロジェクション**：`record` や通常クラスをコンストラクタ経由でマッピング
- **動的プロジェクション**：戻り値型を `<T>` にし、呼び出し側で型を渡す
- **エンティティそのまま**：全カラム取得（プロジェクションなし）

本プロジェクトでは **インターフェースベース** を採用している。
